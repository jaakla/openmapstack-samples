# Idaringtee 21 viewer

UI reference: `concept.png`, generated with the built-in Image Gen tool. Its geographic illustration is not a source and is replaced entirely with recovered PDF vectors and official context.

White 72 px header, 320 px left rail, full remaining viewport as the map, slim bottom status line. On narrow screens the map precedes the controls. Fraunces-like Georgia headings; system sans-serif interface. White surfaces, charcoal text, #bb684e proposed buildings, slate existing buildings and sage green public green plots. Thin neutral rules; segmented controls and compact switches. No card grid.

Primary controls: Explore / Sources; Proposal / Existing; 2D / 3D; reset; independent layer switches; plan / neighbourhood extent; pitch; map / aerial background. Click buildings or plots to show source, drawn footprint, permitted counts and height basis. The terrain and massing use measured/source-backed data, with no generated map geometry or decorative trees.

Intentional additions to the concept: drawing opacity, terrain toggle, source-document links, source limitations and plot inspection are required for faithful GIS interpretation. Actual geography, street pattern and building shapes replace the illustrative design concept. The exact generation prompt is retained in the conversation; the visual reference is an interface composition only.

The interface is in Estonian. The requested goplex.ee OSM vector styles provide the default light/dark basemap; the retained Maa-amet raster and orthophoto remain selectable. A shared land-use palette distinguishes commercial, apartment, terraced and duplex development: saturated building masses and pale matching POS plots, shown together in the legend. Explicit rotation buttons, a bearing slider and a left-button rotation mode support mouse use. Utilities and functional-context annotations are source-recovered thematic vectors with their own switchable legends.
